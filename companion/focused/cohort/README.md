# Focused cohort and feature coverage — label-free aggregate

This local report describes the approved, already prepared four-arm test feature views. It is not a score, prediction, outcome analysis or proof of prospective availability. The source reporter reads six hash-verified label-free views and metadata only; it never reads predictions or outcome labels. No entry identifiers, pedigree maps, source feature rows, model files or credentials are included here. External availability and redistribution rights remain unverified.

- `test_representation.csv` has 12 rows: two graph regimes × three seeds × two surfaces, with entries, complete races, direct/fallback/missing counts and fallback depth 1–3 counts.
- `test_joint_distribution.csv` contains every observed status × depth × unique-ancestor-count × missingness combination for each view, seed and surface. Its fraction uses all entries in that surface as denominator. A blank depth denotes a missing representation; direct vectors have depth 0 and ancestor count 0. Identical counts do not imply identical vector values or distributions.
- `test_parent_availability.csv` has 36 rows: six views × two surfaces × three parent roles. It reports identifier availability/missingness, known-identifier zero-prior counts, and total zero-prior counts. Fractions explicitly use all surface entries except `known_id_zero_given_available_fraction`, which conditions on identifier availability. A zero prior count is not the same concept as an unseen categorical parent token in the older B baseline.
- `train_validation_feasibility.csv` copies only previously checked label-free first-available-ancestor depth and identifier-availability counts from the frozen feasibility source. It does not report train/validation P prior-outcome counts or imply that historic pedigree-record availability was verified.
- `SUMMARY.json` records exact source/report/output SHA-256 hashes and runtime/scope. Six actual view hashes and sidecars were checked; full race fields and keys, all P values and surface assignments match across views. Representation status and parent zero counts also match the hash-verified inference metadata. Prior separate all-row graph, centroid and parent-map checks were bound by their reviewed report hashes.

Each test view contains 89,137 entries: 43,477 turf in 3,246 complete races and 45,660 dirt in 3,219 complete races. All values are entry-weighted. The local aggregation ran in Python 3.14.3/NumPy 2.4.4, while the native view runtime reported Python 3.13.15/NumPy 1.26.4; this is a cross-runtime check rather than a claim of environment identity. The native runtime report was separately checked, SHA-256 `03a35c12bb4e35c8e22d0eae3fcba7d48b7688bd4cf01228040468a35dc90d5f`.

`../reporting/report_focused_cohort.py` is the source of this report. Running it again requires the six restricted feature views, their reviewed quality reports, the inference metadata report and the frozen label-free feasibility file; none of the restricted views is in this folder. Provide those approved local paths and a new output directory using the script's `--help`. The internal reference keys and P values are held in memory only. The lead independently regenerated the five report outputs from the actual six views and obtained byte-identical results; this is an internal verification, not a public data release.
